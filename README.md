# PathWeaver

レタリング・ロゴ制作向けの、可変幅SVGパスエディターです。

| 層 | 中身 |
| --- | --- |
| `pathweaver-core/` | Rust。ベジェ・可変幅・25種類のノード効果・検証・保存形式・SVG書き出し。画面に依存しない唯一の正解。 |
| `pathweaver-wasm/` | coreをwasm32に出すJSONブリッジ（wasm-bindgen不要）。 |
| `pathweaver-web/` | 画面すべて。Vue 3＋[Tweeq](https://github.com/baku89/tweeq)の実コンポーネント。キャンバス（SVG）、ノードエディター、パス一覧、プロパティ。 |
| `pathweaver-mac/` | Swiftのホスト。WKWebView 1枚と、メニュー・開く／保存パネル・終了確認だけを担当。 |

以前の「GPUIの画面にTweeqの設定欄だけWebViewで埋め込む」構成は廃止しました。継ぎ目（ノード上で値を触れない、色のドラッグで下の文字が選択される等）をなくすため、画面は1つのWebページに統一しています。`pathweaver-gpui/` は参照用に残してあり、ビルドには使いません。

## 開発

必要なもの：Rust（`rustup target add wasm32-unknown-unknown`）、Node.js 20以上、Xcode Command Line Tools（`swiftc`）。

```bash
./run-pathweaver.sh          # PathWeaver.app をビルドして起動（dist/PathWeaver.app）
./run-pathweaver.sh --dev    # ブラウザで開発 http://127.0.0.1:5174
./run-pathweaver.sh --test   # core・wasm・vendorパッチ・WebKitでのE2Eテスト
./scripts/build-macos-app.sh --output-dir /path/to/folder   # 指定フォルダーの PathWeaver.app を更新
```

アプリは同じ `PathWeaver.app`（Bundle ID `com.onmokoworks.pathweaver`）を更新し続けます。インストール後はNode.js・サーバー・ネットワーク接続は不要です（HTML・JS・アイコン・wasmを1つの `index.html` に内包）。

## 操作

ツールはキャンバスに浮かぶパレット。上のつまみ（⋮⋮）をドラッグで移動、ダブルクリックで縦／横を切替（位置と向きは記憶）。ポインターを重ねると名前とキーが出ます。下のステータスバーに、いまのツールの使い方を表示します。

- **P ペン**：クリックで角、ドラッグで曲線（Optionで片側ハンドルだけ）。直前の点をクリック→ドラッグで出ていくハンドルだけを付け直し。始点で閉じる。Enter／Escで終了。
  - 既存パスの線分に重ねると「＋」カーソル。クリックで形を保ったままアンカーを追加。
  - 開いたパスの端点をクリックすると、その続きから描画。
  - **Shift＋パスをクリック**で、アンカーを足さずにそのパスの上から描き始め。次の点は**そのパスの法線方向**に吸着し、法線は点線で表示（描画中のShift＋クリックは、点をパスの上に置く）。
- **A ダイレクト選択**：アンカー・ハンドル・線分をドラッグ。線分を **Option＋クリック** または **ダブルクリック** でアンカー追加。Optionでハンドルを独立。Shiftで追加選択・水平垂直。
- **⇧C アンカーポイント**：クリックで角、ドラッグでスムーズ。ハンドルのドラッグは片側だけ。
- **V 選択**：クリック・範囲選択・移動。選択枠の角で拡大縮小、角の少し外側で回転（Shiftで比率固定／角度刻み、Optionで中心基準。Option＋ドラッグで複製して移動）。ガイドの移動も。

### 太さ（専用ツールなし。A・P・⇧Cの中で操作）

最初のPathWeaver（e4c9924）と同じ操作です。選択中パスの太さのつまみ（輪郭の10px外の小さな丸）が常に表示されます。

| 操作 | 動作 |
| --- | --- |
| つまみをドラッグ | 左右に同じ量を足す（左右差は保つ）。つまみの横に「両側」 |
| Option＋つまみをドラッグ | その側だけ。Optionを押すと掴む側が「この側だけ」と表示され、反対側が薄くなる |
| ⌘＋芯をクリック | 幅点を追加（その場の太さで確定。前後の太さを変えても動かない） |
| ⌘＋幅点のつまみ（どこでも）をドラッグ | 幅点を芯に沿って移動（太さはそのまま） |
| ⌘＋始点・終点をドラッグ | 切り口を回転（Shiftで角度刻み）。プロパティの「−」で直角に戻す |
| 幅点の中心をクリック → Delete | 幅点を削除 |

プロパティでは、選んだ幅点の「太さ」（左右に同じ量）・「左だけ」・「右だけ」・「方向」を数値で変えられます。「太さハンドル：常に表示」をオフにすると、⌘を押している間だけ表示されます。

- キャンバス左下の「吸着」バーで、ガイド・グリッド・接線・法線をワンクリック切替（接線・法線は他のアンカーを通る方向）。
- 定規からドラッグでガイド。定規へ戻すと削除。Controlを押している間は吸着しない。
- 上部バーの空いた所をドラッグでウィンドウ移動、ダブルクリックでウィンドウを画面いっぱいに（システム設定の「タイトルバーのダブルクリック」に従う）。フルスクリーンは⌃⌘F。
- 吸着はキャンバス左下のバーのほか、メニューバーの「表示」からもチェック式で切替。
- パン：2本指スクロール／スペース＋ドラッグ／中ボタン。ズーム：ピンチ／⌘＋スクロール。F・⌘0で全体、⌘1で100%。
- ⌘Z／⇧⌘Z、⌘D複製、Delete、矢印キーで移動（Shiftで10）。

### レイヤー（右上）

前面が上。各パスに形のサムネイル。行をドラッグで並べ替え、フォルダの上に落とすと中へ、外に出すと抜ける。⌘Gで選択をフォルダにまとめ、⇧⌘Gで解除。フォルダは名前変更（ダブルクリック）・開閉・表示切替（非表示はキャンバス・書き出しから除外）。

### プロパティ（右）

Tweeqの `ParameterGrid` で、選択内容に応じて表示します。

- **塗り・線**：色があるときは色欄と「−（なしにする）」、ないときは「＋ なし — 追加」。チェックボックスと色欄を並べる方式はやめました。複数選択では全パスに適用し、値が違えば「混在」。
- 線幅（幅点の比率を保つ）、角の形、**線端（平ら／丸／四角）**、位置とサイズ（X/Y/W/H）。
- **角丸**：アンカーを選ぶと半径と種類（円弧／クロソイド／面取り）。ダイレクト選択では角の内側の丸をドラッグで半径、Option＋クリックで種類。
- アンカー選択時：座標、角／スムーズ／独立、点で分離・端点を連結・直線にする（隣り合う2点）・削除・マージ（中心／最初／最後）。
- 操作ボタンはラベル付きでその内容の近くに配置しています。

### ノード（下）

選択中のパスの外観ノードを編集します（Blender／Node Wrangler準拠）。

- **値はノードの上でそのまま編集**（TweeqのInputNumber：ドラッグ・クリックで入力・式入力）。色・チェック・選択肢もノード上。
- 数値ソケットに「値」「計算」などをつなぐと、その欄は描画と同じ評価器で計算した実効値 `↗ 値` を表示。
- ソケットからドラッグで接続。つながった入力をドラッグすると付け替え、空白で離すと切断。空の入力からも引き出せます。
- **未接続のノードをリンクの上に落とすと、その間に挿入**（重なる下流ノードは右へずらします）。追加メニューの項目をそのままリンクへドラッグしても挿入できます。
- 線はソケットぴったりでなくても、**ノードの上や近くで離せば合うソケットにつながります**。線を空白で離すと追加メニューが開き、選んだノードがその線につながります（入力から引き抜いた線は空白で離すと切断）。
- Shift＋A：ポインター位置に追加メニュー（日本語・英語で検索）。**追加したノードはポインターに付いてきて**、リンクの上で光ったらクリックで割り込み挿入（Blender）。Escで追加を取消。
- G：選んだノードをつかんで移動（クリック／Enterで確定、Esc／右クリックで取消。リンクの上なら挿入）。
- **Option＋ノードからノードへドラッグ**（またはAlt＋右ドラッグ）：相性の良いソケット同士を自動接続（Node Wranglerの Lazy Connect）。
- **Ctrl＋右ドラッグ**：横切ったリンクを切る（Cut Links）。**Ctrl＋X**：つなぎを保ったまま削除（Dissolve）。
- **ラスターのノード**：ラスター化（解像度はノードで固定）→ラスターぼかし／しきい値／ノイズ→画像トレースでベクターに戻す。ラスターをベクター用ノードにつなぐと自動でトレース、出力がラスターならPNGとして描画・SVGに埋め込み。
- **Ctrl＋ノードをドラッグ**：リンクから外す（前後はつなぎ直す）。ノードの箱をリンクに重ねて離すと割り込み挿入。
- X／Delete削除、Mバイパス、F／Homeで全体表示。
- 重い効果（メゾティント→ぼかし等）は別スレッドで計算し、終わるまで直前の見た目を表示（画面は固まりません）。
- 「メゾティント」：形の中をランダムな粒（点／線）で埋める。密度・粒の大きさ・線の角度・シード・粒の形をノード上で設定。
- ノードエディター上部のバーで、外観のオン／オフ、**セット名の編集・保存（上書き）・呼び出し（選択中のパスへ適用）・削除**。

## テスト

`pathweaver-web/e2e/` のPlaywrightテストはWebKit（WKWebViewと同じエンジン）で実際にマウス・キーを操作し、文書データで結果を確かめます。ペン（角・曲線・曲線→角→曲線）、太さ（両側・Option片側・⌘で追加／移動／切り口回転・描画中の調整）、線分上のクリック／Option＋クリック／ダブルクリックでのアンカー追加、ノード上での値の入力とドラッグ（Undoが1回で戻ること）、リンクへのドロップ挿入、ソケット接続、色ピッカーを画面外までドラッグしても文字が選択されないこと、ガイドなど。
