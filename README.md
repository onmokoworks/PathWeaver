# PathWeaver

Rust製の、レタリング・ロゴ制作向け可変幅SVGパスエディターです。
Macの新しいフロントエンドは **GPUI**。キャンバス、パス一覧、設定欄、下部ノードエディターをGPUIで描画します。
ベジェ曲線・可変幅・25種類のノード効果・保存形式は、UIに依存しない `pathweaver-core` で共通化しています。

## Macで開発する

Xcode（Metalツールチェーンを含む）と [Rust stable](https://rustup.rs/) を用意し、リポジトリ直下で実行します。

```bash
./run-pathweaver.sh           # GPUI版を起動
./run-pathweaver.sh --release # 最適化ビルド
./run-pathweaver.sh --test    # 共通コア＋GPUI版のテスト
./run-pathweaver.sh --check   # 共通コア＋GPUI版のClippy
./run-pathweaver.sh --legacy  # 互換確認用のegui版
```

初回は依存ライブラリの取得とビルドに時間がかかります。GPUIは `0.2.2` に固定し、Macのテキスト表示に必要な `font-kit` 機能を有効にしています。日本語UIはmacOSのヒラギノを使用します。

### Finderから起動する

```bash
./scripts/build-macos-app.sh --debug
open dist/PathWeaver.app
```

Macアプリは同じ `PathWeaver.app` を継続更新します。機能別のアプリ名やBundle IDは増やしません。配布先を固定する場合は `./scripts/build-macos-app.sh --debug --output-dir /path/to/folder` を使うと、そのフォルダーの `PathWeaver.app` を更新します。起動中なら作業を保存して閉じてから再実行してください。従来egui版を明示的にビルドする `--legacy` だけは `PathWeaver-Legacy.app` として区別します。

`--debug` を省くと最適化版、`--legacy` を追加するとegui版を作ります。
ビルドしたMacのCPU向けのローカルアプリで、署名はアドホック署名です。
GPUI版とegui版は別のbundle IDなので、従来版の作業を保ったままGPUI版を試せます。

## GPUI版の操作

- **P**：ペン。クリックで点、ドラッグでベジェハンドル。Enterで1本を終了。始点をクリックすると閉じます。
- **V**：パス選択。空白から範囲選択、Shiftで追加・解除。選択パスをまとめて移動・拡大縮小・回転・複製・削除できます。
- **A**：制御点を編集。Shift＋クリック／空白から範囲選択で複数点を選択。Deleteは選んだ点を削除します。Optionで片側ハンドルを独立させます。
- **Shift+C**：アンカーポイントツール。点をクリックして角に、点からドラッグしてスムーズな曲線に変換します。
- ペンで描画中の終点をクリックすると、前の曲線を保って次の点を直線でつなげます。
- 制御点ツールで線分をダブルクリックすると形を保って点を追加。Option＋線分クリック、または「次の線分を直線化」で既存の曲線を直線にします。
- **W**：幅ハンドル。パスをダブルクリックして幅点を追加。Optionで左右を別々に変更します。
- 2本指スクロール／中ボタンドラッグ：パン。Cmd＋スクロール／マウスホイール：ポインター位置でズーム。HomeまたはF：全体表示。
- Cmd+O／S／Shift+S：開く／保存／別名保存。Cmd+E：SVG書き出し。
- Cmd+Z／Shift+Z：Undo／Redo。Cmd+D：パス複製。Cmd+Q／W：終了（未保存なら確認）。

### 配置とパラメーター操作

ThreadShapeを参考に、上部にツール、右側にパス一覧と「プロパティ／グリッド・ガイド」、下部にノードを配置しています。設定入力中もキャンバスの位置は変わりません。上部の「配色」でライト／ダークを切り替え、次回起動時にも選択を保持します。作品の色は変更しません。

Tweeqのコンパクトなパラメーター操作を参考に、点のX/Y、線幅、回転、拡大率、グリッド間隔、各ノードの数値を共通の入力欄にしました。

- 数値をクリック：その場で入力。Enterで適用、Escapeで取消。
- 横ドラッグ：値を調整。Optionで0.1倍、Shiftで10倍。Qを押している間は刻みに合わせます。
- 入力中の↑／↓：1段階ずつ増減（Option／Shiftも使用可）。
- `100 / 3`、`(x + 10) * 2`のような四則演算に対応。`x`は編集開始時の値です。
- ドラッグ中はプレビューし、離すと確定。ドラッグ全体を⌘Z 1回で戻せます。Escapeで開始前へ戻します。
- 回転は現在の形からの角度、拡大率は現在の形に対する倍率です。適用後は0°／1倍に戻ります。
- 他ノードから接続されたパラメーターは、接続元の数値ノードで調整します。

TweeqのVueコンポーネント自体は組み込まず、GPUIで操作を実装しています。任意のJavaScript実行、複数パラメーターの範囲選択、縦方向での速度変更には未対応です。
仮のツールアイコンは `pathweaver-gpui/assets/icons/*.svg`、UIフォントは `pathweaver-gpui/src/assets.rs` の `UI_FONT` を変更して再ビルドできます。現在はmacOSのHiragino Sansを使い、フォントファイルは同梱していません。

### 点の座標・分離・連結・マージ

制御点を選ぶと右側にX/Y座標と編集ボタンが現れます。座標は文書単位です。複数点の座標入力は最後に選んだ点を基準に、相対位置を保って全選択点を移動します。

- 「角」「スムーズ」「独立」でハンドルを切り替えます。
- 「点で分離」は開いたパスの途中を2本に分割し、閉じたパスならその点で開きます。可変幅・効果グラフを引き継ぎます。
- 「端点を連結」はShiftで選んだ2端点を直線でつなぎます。同じパスの両端なら閉じます。
- **M** または「点をマージ」で、右側に「中心へ」「最初に選択した点へ」「最後に選択した点へ」を表示します。中心は選択点の平均座標です。最初／最後はShift＋クリックなどで点を選んだ順番を使います（範囲選択はパス一覧順・パス上の点順）。
- 同じパスの連続した複数点、または別パスの2端点を1点にまとめ、外側のハンドルを保持します。同じ開いたパスの両端をマージすると閉じます。全点を選ぶと1点になり、線は表示されなくなります（Undo可）。離れた途中の点を1つにまとめる分岐構造には未対応です。
- 別パスを連結／マージすると、最初に選んだパスの色・効果グラフを使います。
- 「輪郭を合体」は複数パスの表示輪郭を和集合にします。効果を焼き込み、最初に選択したパスの塗り色（なければ線色）の単色にします。元の芯・幅点を編集するにはUndoしてください。

### 接線・法線スナップ

右側の「グリッド・ガイド」で接線・法線・ガイド・グリッドの吸着を切り替え、「間隔」で文書単位の間隔（1〜10000）を設定できます。ペン描画、点・ハンドルの編集、選択パスの移動に対応します。吸着中は種類と補助線／吸着点を表示し、Controlで一時解除できます。

- 上の定規から下へドラッグすると横ガイド、左の定規から右へドラッグすると縦ガイドを作れます。
- **V**でガイドの線をドラッグして移動。定規やキャンバス外へ戻して離すと削除します。パスと重なる場所ではパスの選択を優先します。
- ガイドは画面上8ピクセル以内で吸着し、縦横の交点にも合います。グリッド併用時はガイドに拘束されない軸をグリッドへ合わせます。
- パス移動はクリック位置に最も近い選択アンカー（輪郭のみなら選択範囲の左上）を基準に、選択全体の相対位置を保って吸着します。
- 接線／法線はドラッグ開始時のアンカーと他の表示アンカーの方向を固定して参照します。優先順位はガイド → 接線／法線 → グリッドです。

ガイド・間隔・吸着設定は文書に保存し、追加・移動・削除はUndoできます。画面上8ピクセルより細かいグリッド線は省略表示しますが、指定間隔での吸着は有効です。

### 下部ノードエディター

「ノードを編集」で選択パスに効果を追加できます。境界を上下にドラッグして高さを変更できます。
種類ごとの見出し色、個別のノード名、形状・数値ソケットを備えています。

| 操作 | 動作 |
| --- | --- |
| Shift+A | ノード追加欄。日本語・英語の種類名で検索 |
| ドラッグ / Shift+クリック / 空白からドラッグ | 移動 / 複数選択 / 範囲選択 |
| G / Shift+D / M / X | 移動開始 / 複製 / 有効・無効 / 削除 |
| Home / N | 全ノードを表示 / 設定欄の開閉 |
| ダブルクリック / F2 | ノード名を変更 |
| ソケットからドラッグ | 接続。入力側からは既存接続をつなぎ直す |
| Option+右ドラッグ | Node Wrangler風の自動接続 |
| CtrlまたはCmd+Shift+クリック | 選択ノードを出力へ接続して確認（Undo可） |
| CtrlまたはCmd+右ドラッグ | 線を横切って接続を切る |
| 右クリック（入力ソケット） | 接続解除 |
| Escape | 移動・接続操作を取り消す |

ショートカットはポインターがある編集領域へ作用します。文字入力中は作品の編集キーを無効にします。

「セット」で名前と種類を付けて文書へ登録でき、別パスにも適用できます。
`.pathweaver-nodes` ファイルで書き出し／読み込みも可能です。適用時は独立したコピーになるため、別のパスや保存済みセットは連動して変わりません。
セットを修正して配布する場合は、同じ名前・種類で登録し直して書き出します。

## 保存形式と移行範囲

既存の `.pathweaver` を読み込み、同じ形式で保存します。元の芯、幅点、効果グラフ、名前付きセットを保持します。SVGは共通エンジンの色付き輪郭を出力します。

GPUI版はパス描画・選択・制御点・幅・基本変形・ノード編集の実用経路を移植した初版です。
従来UIのプリミティブ作成ツール、ライブコーナー専用ハンドル、切り口角度の専用UI、差分・交差などのブーリアン操作ボタンは引き続きegui版で利用できます。これらの既存データはGPUI版でも描画・保持します。
ネイティブのピンチ操作はGPUI版では未対応です。Cmd＋スクロールを使用してください。
名前付きセットは再利用できるグラフのコピーで、入れ子のグループや共有インスタンスではありません。
[効果一覧と描画仕様](threadtype-egui/docs/pathweaver-appearance.md)も参照してください。

## 構成

- `pathweaver-core`：文書・ベジェ・可変幅・輪郭・SVG・外観グラフ。GUIライブラリに依存しません。
- `pathweaver-gpui`：Mac用GPUIフロントエンド。入力、セッション履歴、キャンバス、ドック式ノードUI。
- `threadtype-egui`：従来フロントエンドとThreadShape。共通コアを使用し、互換性のテストも維持しています。

Windowsでは `run-pathweaver.ps1`、Linuxでは `./run-pathweaver.sh` が従来のegui版を起動します。GPUI版のWindows・Linux対応は未検証です。
元の円形ペグを使うフォント制作ツールは `./threadtype-egui/run.sh` または `threadtype-egui` 内で `cargo run --locked --bin threadtype` から起動できます。
