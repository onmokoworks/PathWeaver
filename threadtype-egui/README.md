# ThreadShape（Rust版）

円形ペグ・フォント制作ツールのMVP実装。Rust + egui/eframe + kurbo + lyon。

```sh
cargo run            # 起動
cargo test           # 幾何コアの単体テスト
cargo run --release  # 最適化ビルドで起動
```

## 構成

- `src/geometry.rs` — タウトストリング・エンジン（コア）。接線点の解析計算、
  巻き方向の外積判定、アンラップ角による2π超の巻き付き追跡、捕捉/解放の
  ヒステリシス。単体テストはこのファイル内。
- `src/model.rs` — 面（Face）とドキュメントのデータモデル（serde）
- `src/export.rs` — SVG書き出し（円弧はAコマンド、πを超える掃引は分割）
- `src/app.rs` — egui アプリ本体（日本語UI、Undo/Redo、面・サブ円追加/削除、コマンドピン）

## v3 実装方針（仕様反映）

- v3: ペグモデルを `Grid`/`Sub`/`Custom` に統一、サブ円の自動配置（ON/OFF）、任意円の移動・半径編集、拡縮基準（左上/中央）を追加。
- `geometry.rs` の solver 本体は既存仕様どおり据え置き、解決ロジックを `model.rs` に一元化。

- `Face` は `start` と `elements`（`Wrap/Pin`）の**パラメトリック表現**で保持。
- 描画/ヒット判定/SVG は毎フレーム `materialize_face` で実体化。
- サブ円は `grid.subs_enabled` で全セル中心に自動生成。`Sub` 円は `scale_anchor = TopLeft/Center` で位置決定。
- 描画開始は近傍のペグの十字点のみ。空きスペースからは開始不可。
- 任意円（`CustomPeg`）は独立の中心・半径を持ち、選択時にドラッグ移動と半径編集（8〜120）に対応。
- Command 押下中は通常の solver を停止し、直線プレビューとしてピンを打てる（Pin 追加）。
- 拡張コントロールとして `間隔に合わせて円の大きさも変える` と `拡縮の基準（左上/中央）` を追加。
- `面`/`減算` のトグルは廃止。描画面は非零ワインドルールで合成。

## v4 追加機能

- `to_screen / to_world` へ座標変換を集約し、スクロール・Spaceドラッグでのパン、Cmd+スクロールでのズーム、右下ズームボタン（`100%` リセット）を追加。
- 右下ミニマップ（操作中のみフェード）を追加。
- ツールを `描画 / 選択 / ダイレクト選択 / 任意円` に再編。
- ダイレクト選択でグリッド/サブ円をドラッグすると `CustomPeg` へ変換して編集。
- Command 押下時は貫通ペグを `ignored` として `update_thread_ignoring` へ渡し、Pin 追加時に貫通を確定化。
- Command 中は貫通のプレビューを緑表示とし、赤表示は自己交差と2周超巻きのみで扱う。
- `subs_enabled=false` 時でも既存面の再生・表示を保持。
- 面/任意円の可視フラグをデータへ持たせ、右パネルに一覧・表示切替・削除・数値編集を追加。
- 任意円非表示時は描画のみ非表示、ヒット判定と開始点は継続。
- クリアなダーク/ライト切替テーマを追加。

## アルゴリズムの要点

- 線の状態は「アンカー + 巻き付きスタック + 先端」。毎フレーム、
  (1) 末尾の巻きのたるみ解放 → (2) 自由区間の新規巻き付き、を収束まで反復。
- 接線角は解析式で閉じている:
  - 点→円: `entry = θ_P + s·acos(r/d)`, `exit = θ_C − s·acos(r/d)`
  - 円→円: 同方向なら外接線、逆方向なら内接線（交差接線）
- 巻き方向 `s` は自由区間の進行ベクトルと円中心の外積符号で決まる。
  中心を正確に突っ切る縮退ケースも符号タイブレークで潰れない。
- 離脱角はアンラップ済み実数として連続追跡するため、半周以上・複数周の
  巻き付きも安定する。巻き付き量が0を割ったら解放。
- 捕捉は「実効半径より一定深さの食い込み」、解放は「巻き付き角≤0」。
  条件の非対称性がヒステリシスとして働きフリッカーを防ぐ。
