# ノードで外観を編集する

パスを選択し、プロパティの「ノードで外観を編集」から開きます。複数選択時は最後に選択したパスが対象です。パスの芯・幅点・コーナーは編集可能なまま残し、出来上がった塗りと線の輪郭に効果を適用します。グラフはパスごとに`.pathweaver`へ保存し、保存・再読込・Undo/Redoに対応します。元ファイルにグラフがなければ従来と同じ描画です。

## 接続と編集

- 緑の丸は外観（色付き輪郭）、青の丸は数値です。右の出力から、別のノードの左の入力へドラッグ、または順にクリックして接続します。型違い・循環する接続は拒否します。
- 入力の丸をAlt/Option＋クリックすると切断します。右の設定欄の「切断」でも解除できます。
- ノードをクリックすると右側に設定が出ます。ノード自体をドラッグして配置を変え、キャンバスの空白をドラッグして移動します。ホイールで拡大・縮小し、「全体表示」でグラフ全体を収めます。
- 「ノードを追加」から効果を追加し、出力へ接続します。追加しただけの未接続ノードは結果に影響しません。
- 「このノードを無効化」はバイパス。「効果を有効にする」をオフにすると元のパスの外観に戻ります。
- 「ノードを削除」で選択ノードを削除します。入力と出力は削除できません。削除されたノードへの接続は外れます。
- 出力が未接続の場合は何も表示しません。「シンプル」プリセットで元の外観→出力の接続に戻せます。

## ノード一覧

|輪郭|ラフ|大きさ、100単位あたりの細かさ、滑らかさ、シード。継ぎ目のない周期ノイズ|

|輪郭|角を丸くする|収縮と拡張による角丸。半径|
|輪郭|パスのオフセット|正負の距離。ラウンド・マイター・ベベル|
|輪郭|単純化|許容距離で頂点を減らす|
|輪郭|変形|横・縦移動、回転、拡大率。入力外観の外接矩形中心が基準|
|輪郭|縁取りの形|幅、外側・内側・中央、角の接合|
|輪郭|エッジを溶かす|輪郭の欠けと微粒子。量、粒サイズ、散らばり、シード|
|輪郭|かすれ|細い帯で型抜き。本数、細さ、角度、シード|

|色|光彩|大きさ、色、不透明度、内側・外側|

## 保存・書き出しと実装範囲

[mv-text-creatorの外観ノード](https://github.com/onmokoworks/mv-text-creator/blob/main/docs/APPEARANCE.md)を参考にしたPathWeaver向け実装です。同じプロジェクト形式やピクセル単位の効果互換ではありません。

- SVGは画面と同じ色付き輪郭と不透明度を出力します。塗りはNonZeroです。効果を外した元の芯はプロジェクトに残ります。
- ぼかし・光彩は段階的な半透明ベクター輪郭による近似で、Gaussian blurではありません。画面とSVGで同じ近似を使います。
- ラフは固定シードの周期ノイズです。元ツールのSimplexノイズそのものではないため、同じ数値でも形は一致しません。
- 効果の距離は文書座標です。パスを拡大・回転しても効果パラメータは自動変換せず、変形後の芯から再計算します。変形ノードの基準は入力外観の中心です。
- 外観と数値の2種類の接続を採用しています。元ツールの「形」と「絵」は分離せず、色付き輪郭を処理します。通常合成に対応し、乗算・スクリーンはありません。
- パスごとのグラフです。共有プリセット資産、複数パス共通グラフ、グラフのフレーム・折りたたみ・ノード内プレビュー、可変入力スタック、累積コピーは未対応です。
- 処理量には上限があります。極端なノード数・輪郭点数・レイヤー数はエラーを表示し、ハーフトーンなどのサンプル密度は制限します。重い効果を連続でつなぐ際は細かさを控えめにしてください。
