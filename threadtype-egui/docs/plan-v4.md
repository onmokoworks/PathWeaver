# ThreadShape v4 実装仕様（ビュー操作・選択モデル・UI整理）

対象: `threadtype-egui/`。現状 `cargo test` 22件グリーン・警告0。壊さないこと。
`src/geometry.rs` のソルバー本体は変更禁止（本仕様で明示した追加のみ可）。

すでに v3.5 として実装済み（触らない）: ペグごとの描画半径、掃引の枝選択
（sweep_hint）、8方向の開始点、スライダー範囲拡大、ドラッグ編集の履歴修正。

今回のスコープ外（次フェーズに送る。実装しない）: シェイプのマージ＋ベベル、
リッチUI全般、面そのもののドラッグ移動。

## WP1 ズーム / パン

- `App` に `view: ViewTransform { offset: egui::Vec2, zoom: f32 }` を追加
  （ドキュメントには保存しない。zoom は 0.2〜4.0 にクランプ）。
- ワールド座標（既存の全ロジックの座標系）とスクリーン座標の相互変換を
  `to_screen(p) / to_world(p)` の2ヘルパーに集約し、canvas 内の全描画・全入力を
  この経由に統一する。**幾何・ドキュメント側はワールド座標のまま一切変えない**。
- 操作: スクロール = パン、ピンチ / Cmd+スクロール = カーソル中心ズーム
  （egui の `input.smooth_scroll_delta` と `zoom_delta` を使用。トラックパッドの
  ピンチは zoom_delta に来る）。スペース+ドラッグでもパン。
- キャンバス右下に小さな「− / 100% / ＋」ボタン群（下に詰めた控えめなUI）。
  100% クリックでズームとオフセットをリセット。
- 線の太さ・マーカー半径などの「見た目の太さ」はスクリーン基準（ズームで
  太らない）。ペグの円はワールド基準（ズームで大きく見える）。
- 注意: `canvas_center`（拡縮基準・中央モードで使用）はワールド座標のまま。
  ビューとは独立。

## WP2 俯瞰ミニマップ

- キャンバス右下（ズームボタンの上）に俯瞰プレビューをオーバーレイ表示:
  全面の外接矩形＋余白を縮小描画（面は塗りのシルエットのみ、ペグは省略可）し、
  現在のビューポート範囲を矩形で示す。
- パン/ズームの操作中と直後だけ表示し、約1秒アイドルでフェードアウト
  （`ctx.animate_value_with_time` などで透明度アニメーション）。
- クリック/ドラッグでの移動は不要（表示のみ）。

## WP3 選択 / ダイレクト選択（Illustrator風）

ツールを4つに再編: 「描画 / 選択 / ダイレクト選択 / 任意円」。
ショートカット: V=選択, A=ダイレクト選択, P=描画, C=任意円（描画中は無効）。

- **選択（V）**: オブジェクト単位。現行の挙動（面クリックで選択、任意円
  クリックで選択・ドラッグ移動・Delete）をこのツールに残す。
- **ダイレクト選択（A）**: 構成要素単位。「一度確定した円の位置を個別で触る」
  モード。
  - クリック: その点にあるペグ（種類問わず）を選択し、そのペグを参照している
    面の輪郭を薄くハイライト。
  - **グリッド円 / サブ円をドラッグすると任意円に変換して動かす**:
    1. 新しい `CustomPeg`（中心=元位置、半径=元の表示半径）を作成
    2. ドキュメント内の全 Face の該当 `PegRef`（start.peg と elements 内）を
       新しい `Custom { id }` に置換
    3. 以後は通常の任意円としてドラッグ追従
    - 履歴はドラッグ終了時に1回（変換＋移動をまとめて。undo で変換ごと戻る。
      既存の push_history_snapshot パターンに従い「変更前スナップショット」を積むこと）
  - 任意円のドラッグは従来どおり。
- どのツールでも Escape で選択解除。

## WP4 Command（無視）挙動の確定化と赤/緑の再定義

- `ActiveDraw` に `ignored: Vec<usize>`（このストローク中に無視を確定した
  ペグの添字）を追加。
- Command+クリックで Pin を確定した瞬間、その Pin までの直線が貫通していた
  ペグ全てを `ignored` に追加する（貫通ペグの列挙用に geometry へ
  `pegs_penetrated_by_line(a, b, pegs) -> Vec<usize>` を**追加**してよい）。
- ソルバー呼び出しで ignored を除外する。geometry に
  `update_thread_ignoring(th, cursor, pegs, ignored: &[usize])` を**追加**し、
  既存 `update_thread` はそれを空リストで呼ぶ薄いラッパーに置き換えてよい
  （first_hit の exclude を Option<usize> から「last + ignored」into a small
  closure/slice に一般化する程度の内部変更は可。既存テストは全て通ること）。
- 色の再定義:
  - Command 押下中の直線プレビュー: 貫通あり = **緑**（「無視を確定する」意思表示）。
    赤は使わない。
  - 確定後の面でも、Pin 区間がペグを貫通していることは**正当**（無視の確定）。
    赤警告・閉じ禁止の対象から外す。
  - **赤 = 異常** の意味に限定: (a) 描画中の線が自分自身と交差している
    （flatten した折れ線の線分同士の交差判定。隣接区間は除外、点数が多いときは
    間引いてよい）(b) 同一ペグに2周超巻いている。この2つのときは線を赤にし、
    閉じられない。
  - これにより `has_penetration_on_lines` ベースの閉じ禁止・赤表示ロジックは
    自己交差ベースに置き換える。

## WP5 サブ円 OFF で面を壊さない

- `model::resolve_peg` から `subs_enabled` による None ガードを撤去する。
  subs_enabled は「engine_pegs での生成（＝捕捉・開始点・表示）」だけに効かせる。
- 結果: サブ円を OFF にしても既存の面は正常に実体化・表示される（破線不要）。
  ステータスバーの「サブ円を参照する面があります」警告と sub_peg_in_use は削除。

## WP6 表示コントロール

- **円の非表示**: パネルに目アイコン的トグル「円を表示」+ ショートカット **H**。
  非表示は見た目だけで、捕捉・開始点は機能し続ける（開始マーカーは表示する）。
- **面・任意円の一覧パネル**: 右パネル下部にスクロール領域を2つ:
  - シェイプ一覧: 各行 = 小さなプレビュー（flatten を 40×40 に正規化して
    `painter.add(Shape::closed_line)` で描く）+ 表示/非表示トグル + 削除ボタン。
    行クリックで選択（選択ツールと同じ Selection::Face）。
  - 任意円一覧: 各行 = 「円 #id (x, y) r」表記 + 表示/非表示 + 削除（参照中は
    無効化しツールチップで理由）。行クリックで選択。
  - モデル変更: `Face` に `#[serde(default = "default_true")] visible: bool`、
    `CustomPeg` にも同様の `visible` を追加。非表示の面は塗り・輪郭・SVG から
    除外。非表示の任意円は描画されないが幾何としては存在し続ける。
- **任意円の数値編集**: 選択中の任意円パネルに X / Y / 半径 の
  `egui::DragValue`（変更確定は失フォーカス/ドラッグ終了で履歴1回。
  radius_edit_orig と同じ「変更前スナップショット」パターン）。

## WP7 モノクロテーマ（ダーク / ライト）

- 色定数を `struct Theme { bg, peg_stroke, peg_fill, catch, face_fill, thread,
  select, start, warn_red, ok_green, cmd_green, ... }` に整理し、
  `Theme::dark()` / `Theme::light()` を用意。
- 方針: キャンバスは基本モノクロ（ダーク: 黒背景・白〜グレーの線と面 /
  ライト: 白背景・黒〜グレー）。有彩色は 警告=赤、閉じ可能=緑、
  Command確定=緑、選択=控えめな青 のみ。糸の色もモノクロ
  （ダーク: 白、ライト: 黒）に変更する。
- パネル最上部に「ダーク / ライト」トグル。egui の Visuals も連動して切替。
  設定はドキュメントではなくアプリ状態（保存不要）。

## 実装メモ

- ズーム導入で `first_hit` 等の幾何はワールド座標のまま動くので触らない。
  ヒット判定に使う「画面上の距離しきい値」（START_SNAP, CLOSE_RADIUS 等）は
  スクリーン基準にしたいので、ワールド換算（値 / zoom）して使うこと。
- 一覧パネルの削除・トグルも意味単位の履歴1回。
- Selection 型は Face(usize) のインデックス参照なので、一覧からの削除で
  インデックスがずれる点に注意（選択解除してから削除）。
